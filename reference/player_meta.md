# Meta data on players listed at ESPNCricinfo

A dataset containing the names and other attributes of players who
appear on both [cricsheet](https://cricsheet.org) and
[ESPNCricinfo](https://www.espncricinfo.com), as at 24 March 2025.

## Usage

``` r
player_meta
```

## Format

A data frame with 16101 rows and 11 variables.

## Source

<https://www.espncricinfo.com>
